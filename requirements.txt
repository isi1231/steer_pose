# SteerPose 复现 —— Python 依赖
#
# 适用环境: Ubuntu 20.04/22.04 + NVIDIA H100 (sm_90) + CUDA 12.x 驱动
# Python: 3.10 ~ 3.12
#
# 安装顺序（务必先装 PyTorch 的 CUDA 版，再装其余包）:
#   pip install torch --index-url https://download.pytorch.org/whl/cu124
#   pip install -r requirements.txt
#
# 国内服务器（清华镜像）:
#   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
#   # PyTorch 的 cu124 wheel 走清华 pytorch-wheels 镜像:
#   pip install torch --index-url https://mirrors.tuna.tsinghua.edu.cn/pytorch-wheels/cu124
#
# 说明: H100 需要 PyTorch >= 2.1（sm_90 支持），推荐 2.4~2.6 的 cu124 版本。
#       本模型极小（约 100K 参数），单卡 H100 跑训练属于严重过剩，
#       主要收益在于能一次性把 num_pairs 和 batch 开大、快速扫超参。
